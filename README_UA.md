## Що вміє програма

- **Ринки** з перемикачем **Крипта · Мемкоїни · Акції**:
  - **Крипта:** ціни в реальному часі, оцінка **ВИГІДНО / ЧЕКАТИ / НЕВИГІДНО** (бал 0–100), індекс страху і жадібності.
  - **Мемкоїни:** DOGE, SHIB, PEPE, BONK, WIF, FLOKI, TRUMP та інші. Є обсяги й позначка ризику. **Чесно: передбачити, які мемкоїни виростуть, не може ніхто.** Оцінка показує лише тренд та імпульс зараз.
  - **Акції США:** 72 великі надійні компанії та фонди (Apple, Microsoft, NVIDIA, JPMorgan, Coca-Cola, S&P 500, золото GLD, срібло SLV…). Фільтр за секторами й пошук. Дані оновлюються щодня після закриття біржі.
- **Графік:** 121+ актив у групах (мій список, мемкоїни, популярна крипта, золото й індекси, акції) і пошук «Знайти актив». Свічки 15хв / 1г / 4г / 1д / 1т, середні EMA, обсяг, RSI, стрілки сигналів.
- **Чому така оцінка:** кожен фактор зі своїм внеском. **План угоди:** вхід, стоп-лос, ціль і скільки купляти.
- **Пульс ринку:** тиск покупців і продавців у книзі заявок, потік угод і **великі угоди «китів»** у реальному часі.
- **Новини:** лідери росту й падіння за добу, мем-сканер, стрічка новин трьома мовами.
- **P2P-калькулятор**, **Школа трейдера** (10 уроків), **Підключення** (усі сайти й сервіси та їхній стан наживо).
- **Налаштування:** мова 🇺🇦/EN/RU, тема, колір, вигляд карток, свої монети (додати, видалити, порядок), приховування мемкоїнів і акцій, депозит і ризик.
- Працює плавно й **швидко**: усі розрахунки йдуть прямо на вашому пристрої.

## Що вміє Telegram-бот

- 🟢 **Сигнали купівлі** з поясненням, планом і картинкою графіка. 🔔 **Зміна оцінки.** 🔴 Злам тренду. 🟡 Перекупленість. ⚡ Різкі рухи.
- ☀️ **Ранковий огляд** (~8:00 за Києвом): оцінки, страх і жадібність, **акції, що виглядають вигідно**, головні новини.
- 🧪 **Віртуальний портфель** зі щотижневим звітом.

## Що вміє торговий робот

- Стежить за обраною криптою (BTC, ETH, SOL…) і акціями (SPY, QQQ, AAPL…) 24/7.
- Є три режими:
  - **з підтвердженням** (за замовчуванням): присилає «🟢 Сигнал купівлі · BTC» з кнопками **[✅ Купити на $X] [❌ Пропустити]**;
  - **авто**: купує сам;
  - **вимкнено**: нових угод не відкриває.
- Відразу після покупки **ставить стоп-лос на біржі**. Ціль продає сам.
- Захист:
  - ризик 1% на угоду;
  - не більше 20% капіталу в одну угоду;
  - максимум 3 відкриті угоди;
  - денний ліміт збитку 3%;
  - максимум 4 угоди на день.
- Команди в Telegram: `/status`, `/positions`, `/buy BTC 50`, `/buy AAPL 100`, `/sell BTC`, `/mode`, `/pause`, `/resume`, `/panic`.
- Команди приймаються **лише з вашого чату**.
- **Гроші лежать на вашому рахунку Alpaca.** Робот лише надсилає ордери через ключ API.

## Частина 1. Програма і бот (≈ 20 хвилин, безкоштовно)

### Крок 1. Telegram-бот
1. У Telegram відкрийте **@BotFather** і напишіть `/newbot`. Ім'я: `TrendRadar`. Логін: будь-який, що закінчується на `bot`.
2. Збережіть **токен** (`1234567890:AAH…`) і **нікому його не показуйте**.
3. **Аватарка:** у @BotFather напишіть `/setuserpic` і надішліть файл `assets/avatar.png`.
4. Напишіть своєму боту «привіт», потім відкрийте в браузері `https://api.telegram.org/bot<ТОКЕН>/getUpdates`. Число з `"chat":{"id":…` — це ваш **CHAT_ID**.

### Крок 2. GitHub
1. Зареєструйтесь на **github.com**. Натисніть **New repository**, назва `trendradar`, тип **Public**.
   - Публічний, бо так сайт і щогодинна робота безкоштовні без обмежень.
   - Токени з кроку 3 **ніхто не побачить**.
   - `config.json` буде видно всім. Депозит у програмі вводиться окремо і зберігається лише на вашому пристрої.
2. **uploading an existing file** → перетягніть **усі** файли й папки з архіву.
3. ⚠️ Перевірте, що є прихована папка `.github`. Якщо ні: **Add file → Create new file**, назва `.github/workflows/bot.yml`, вставте вміст файлу. Так само для `backtest.yml` і `setup.yml`.

### Крок 3. Секрети
**Settings → Secrets and variables → Actions → New repository secret**: `TELEGRAM_TOKEN` і `TELEGRAM_CHAT_ID`.

### Крок 4. Сайт
**Settings → Pages → Source: GitHub Actions.**

### Крок 5. Запуск
**Actions → TrendRadar · сигнали, новини, сайт → Run workflow.** Приблизно за 2–3 хвилини:
- у Telegram прийде огляд ринку;
- запрацює сайт **`https://ВАШ-ЛОГІН.github.io/trendradar/`**.

Далі все працює **саме, щогодини**.

### Крок 6. Встановити програму
- **Комп'ютер (Chrome/Edge):** кнопка «Встановити TrendRadar» або значок у адресному рядку.
- **Android:** ⋮ → «Встановити застосунок».
- **iPhone (Safari):** «Поділитися» → «На екран «Додому»».

> 🇺🇸 У США Binance.com заблокований. Програма сама перейде на дзеркало даних або Binance.US. Стан видно у вкладці **Підключення**.

## Частина 2. Торговий робот (Alpaca + сервер ≈ $5/міс)

### Крок 1. Рахунок Alpaca (безкоштовно)
1. Зареєструйтесь на **alpaca.markets**. Іллінойс підтримується для крипти.
2. Перейдіть у **Paper Trading**. Це тестовий рахунок з віртуальними грошима.
3. **API Keys → Generate New Keys**. Збережіть **Key ID** і **Secret Key** (секрет показують один раз). Нікому їх не надсилайте, і мені теж.

### Крок 2. Сервер
1. Орендуйте найпростіший сервер **Ubuntu 24.04**, ≈ $4–6/міс: **Hetzner Cloud**, **Vultr** (є дата-центр у Чикаго), **DigitalOcean**.
2. Ви отримаєте **IP-адресу** і пароль. Підключіться:
   - Windows: відкрийте **PowerShell**;
   - Mac: відкрийте **Terminal**.

```bash
ssh root@ВАШ-IP
```

### Крок 3. Встановлення (3 команди)

```bash
sudo apt-get update && sudo apt-get install -y git
```

```bash
git clone https://github.com/ВАШ-ЛОГІН/trendradar.git
```

```bash
sudo bash trendradar/deploy/setup.sh
```

Скрипт попросить Alpaca Key ID і Secret, токен Telegram і CHAT_ID. Ключі зберігаються **лише на сервері**. Після запуску в Telegram прийде «🤖 TrendRadar Trader запущено». Напишіть `/help`.

### Як користуватись
- **Сигнал прийшов** → натисніть **✅ Купити** або **❌ Пропустити**. Пропозиція діє 60 хв.
- `/status` показує рахунок і режим, `/positions` — позиції з кнопками «Продати».
- `/buy BTC 50` купує BTC на $50. `/buy AAPL 100` купує Apple на $100: коли біржа акцій закрита, покупка відбудеться при відкритті.
- `/mode` перемикає режим (з підтвердженням / авто / вимкнено). `/pause` і `/resume` зупиняють і відновлюють нові угоди.
- `/panic` закриває все й скасовує ордери (з підтвердженням).
- Налаштування робота в `config.json → "trader"`: які активи, ризик, ліміти.

### Обслуговування
- Оновити код (після змін на GitHub):

```bash
cd ~/trendradar && git pull && sudo bash deploy/setup.sh
```

- Журнал роботи:

```bash
sudo journalctl -u trendradar-trader -f
```

- Зупинити робота:

```bash
sudo systemctl stop trendradar-trader
```

### ⚠️ Перехід на справжні гроші
Потрібні **два** перемикачі, щоб не ввімкнути випадково:
1. у `config.json` → `"trader": { "paper": false }`;
2. на сервері у `/etc/trendradar.env` → `TRADER_LIVE=1` і нові ключі **Live** від Alpaca.

**Не робіть цього, доки 2–4 тижні тестового рахунку і «Перевірка на історії» не покажуть стабільний результат.** Починайте з малих сум. Податки з прибутку (IRS) — ваша відповідальність.

## Як рахується оцінка

| Фактор | Бали |
|---|---|
| Старший графік (для 4г — денний, для акцій — тижневий) | ±25 |
| Основний графік | ±15 |
| Молодший графік (для 4г — 1г) | ±5 |
| RSI: відкат або перепроданість у тренді вгору / перекупленість | +10…+20 / −15 |
| Імпульс (MACD) посилюється / слабшає | ±10 |
| Ціна сильно відірвалась від середньої | −10 |
| Страх / жадібність (крипта) | ±5 |
| Свіжий сигнал купівлі | +15 |

**70+ = ВИГІДНО · 41–69 = ЧЕКАТИ · ≤40 = НЕВИГІДНО.** Програма, бот і робот рахують однаково. Це перевірено автотестом на тисячах свічок.

## Налаштування бота (`config.json`)

| Параметр | Що означає |
|---|---|
| `language` | мова повідомлень: `uk`, `en`, `ru` |
| `deposit_usd`, `risk_per_trade_pct` | депозит і % ризику (для порад бота) |
| `timeframe` | свічки бота: `1h`, `4h`, `1d` |
| `assets` | що аналізує бот; `"enabled": false` вимикає |
| `news_feeds` | (необов'язково) свої RSS-стрічки |
| `trader` | налаштування торгового робота (див. вище) |

## Чесно про обмеження
- **Гарантій немає.** Оцінка не передбачає майбутнє.
- **«Вгору чи вниз за 20 секунд» не передбачити.** Замість цього є «Пульс ринку».
- **Мемкоїни** — лотерея. Вкладайте лише те, що готові втратити.
- **Twitter/X** не підключено: його API платний. Новини беруться з відкритих видань.
- **Акції в програмі** — ціни закриття дня (Yahoo Finance). Робот торгує за ринковими цінами Alpaca.
- **P2P-курси** вводяться вручну.
- Публічний репозиторій без змін 60 днів: GitHub вимикає щогодинний запуск. Щоб увімкнути знову, натисніть «Enable workflow» в Actions.

## Якщо щось не працює

| Проблема | Що зробити |
|---|---|
| Не приходять повідомлення бота | Перевірте секрети GitHub і що ви написали боту «привіт». Журнал — в Actions. |
| Сайт показує 404 | Settings → Pages → Source: **GitHub Actions**, потім Run workflow. |
| У програмі «ДЕМО» | Відкрийте **Підключення**: там видно, яка біржа недоступна. Спробуйте іншу мережу. |
| Робот мовчить | `sudo journalctl -u trendradar-trader -f`. Перевірте ключі в `/etc/trendradar.env`. |
| «Не можна: …» | Спрацював захист (ліміт угод чи збитку, пауза). Причина вказана в повідомленні. |
